# How to Customize the Tooltips in React Charts of Syncfusion

A quick-start react project that helps you to learn how to enable and customize the tooltip in Syncfusion React charts. This project also contains code snippets to format the tooltip content and render an HTML template in the tooltip.

## Project Overview

This repository shows how to enable tooltips, format content, and render HTML templates in Syncfusion React charts. It includes a small React sample and links to documentation and live examples.

## Features

- Enable and customize Syncfusion chart tooltips
- Format tooltip text and values
- Render custom HTML tooltip templates
- Minimal example showing integration in React

## Prerequisites

Make sure you have Node.js and a code editor such as Visual Studio Code installed on your machine.

## Installation

1. Clone the repository: `git clone <repo-url>`
2. Install dependencies: `npm install`
3. Start the app: `npm start`

## Usage

Open the project and run the development server. Inspect `src/App.tsx` and `data.js` to view the tooltip template and formatter implementations.
